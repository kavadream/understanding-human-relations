## 六部内容

1. **认识自己的反应**：知行差距、自尊与防御、猜测和事实。
2. **理解他人的处境**：行为原因、关系与文化期待、利益和规则。
3. **让关心进入日常来往**：倾听、关心、认可与反馈。
4. **开展对话与合作**：表达、分歧、拒绝与影响。
5. **面对冲突与修复关系**：善意失效、承认错误、信任与原谅。
6. **将所学变成能力**：持续行动和陌生情境中的判断。

## 来源与写作说明
